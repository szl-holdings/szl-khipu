Report vulnerabilities to the maintainer via GitHub Security Advisories on
[szl-holdings/szl-khipu](https://github.com/szl-holdings/szl-khipu).

This package is a CPU NumPy silhouette. It does not execute remote code, does
not load Hub `joblib` pickles, and does not claim proven trust.

- `proven_trust` is false.
- Energy is UNAVAILABLE unless an NVML meter is wired — never a fabricated joule.
- BLOCKED stays BLOCKED (`output is None`).
- Do not treat advisory Λ scores as a security boundary. HARD_DENY is the
  security boundary; Λ is Conjecture 1 OPEN.
