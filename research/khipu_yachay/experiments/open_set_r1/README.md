## Why train it?

The original five-intent Multinomial NB was tuned on 540 original synthetic
questions and had weak out-of-domain generalization. Open-Set R1 trains a
multinomial logistic router over word/bigram TF-IDF plus an explicit
`OUT_OF_SCOPE` class. It aims to improve refusal of unrelated topics without
hiding errors behind blanket abstention. Neither model interprets historical
khipu or speaks Quechua.

### Exact data boundaries

- **480** original first-party intent samples (eight of nine existing template
  families per label), **240** newly authored generic negative prompts.
  Training total **720**. All from first-party synthetic text.
- Internal development set: **60** original train-file examples from the
  ninth template family, **72** new negative samples from disjoint generic
  topics. Used solely for a predeclared threshold search.
- The original **80** template-evaluation rows, owner-added **52** post-hoc
  prompts, separate **100** developer-authored challenge, **702** archival KH
  identifier references, historical content, private Brain data and museum
  materials were **not** used for training or threshold selection.
- A read-only training intent was durably recorded **before** fitting. A second
  independently invoked same-code/same-version CPU run reproduced the exact
  model JSON SHA-256 above. This is same-machine reproducibility, not
  independent replication or an external cryptographic signature.
- scikit-learn 1.9.1 was used for **training only**. The serialized JSON is
  bounded and inference uses Python stdlib; no pickle or other executable
  serialized weights are distributed.

|---|---:|---:|---|

| Owner 52-case post-hoc: unrelated | 7/12 false accepted | **7/12 false accepted** | No measured improvement |
| Separate 100-case developer diagnostic: intent | 27/50 correct | **25/50 correct** | **Regression** |

| Specific unsupported historical questions | 15/20 limits/abstain | **13/20** limits/abstain | **Regression** |

All comparison sets are **developer-authored or previously viewed**. They are
not an independently authored prospective evaluation. The original model's
95% synthetic score and this candidate's development success cannot certify
archaeological interpretation, safe autonomous reasoning, calibrated
confidence, universal abstention, or real-world suitability.

**Disposition: HOLD.** The model is a real trained research artifact, not a
successful replacement for the original. No serving API, Khipu weight branch,
GPU allocation, LoRA base, cloud job, release model card or Space changed.

## The actual next training admission

A larger LoRA/QLoRA SFT run is **not justified by this corpus alone**. The
required additions are: rights-reviewed and contributor-attributed numeric
records, source/site-separated prospective human labels, independent OOD and
abstention checks, explicit protections for Indigenous stewardship and
withdrawal, a fixed Qwen/base/tokenizer revision, and an approved GPU budget.
Train a generative assistant to **cite, calculate and abstain** only after
those gates are satisfied. Avoid optimizing against the old viewed challenges
and calling the result independent.
