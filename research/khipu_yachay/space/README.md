# SZL Khipu Yachay — Living Cord Lab

This **research preview** displays a modern cord-arithmetic demonstration, a
702-identifier citation index from Open Khipu Repository v2.1.0, and a genuine
tiny **supervised intent-router trained on synthetic authored text**. It does not
decode historical khipus, use an archaeological corpus as training labels, or
load the separate 1.5B Khipu weights. A classifier score is not truth.

Canonical source: `szl-holdings/szl-khipu`, `research/khipu_yachay/`.
